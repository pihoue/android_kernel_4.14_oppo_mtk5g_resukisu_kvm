怎么解开 / 怎么用
------------------------------------------------------------------------------
解压 (任选其一):
  Linux/PC:   tar -xJf kvm_mt6833_v13_full.tar.xz
  手机 APK:   用 MT管理器 / ZArchiver / RAR / 7-Zip 直接打开 .tar.xz
  Termux:     pkg install xz-utils && tar -xJf kvm_mt6833_v13_full.tar.xz
  (本机 proot Ubuntu 未装 xz, 故 "tar -tJf" 会失败, 属正常)

刷入 (需要 root):
  cd kvm_mt6833_v13_20260913
  su -c "sh flash.sh"                 # 刷 v13
  su -c "sh flash.sh --rollback"      # 回滚到 v12

  手动: dd if=images/boot_kvm_v13.img of=/dev/block/sdc44 bs=4096 && sync
        回读: dd if=/dev/block/sdc44 bs=512 count=38900 | md5sum
             期望 19c834dec1a35bb1d724bd74b35d0009

重新编译:
  源码用 kernel-source/ , 命令 bash tools/build_v11.sh
  (详见 kernel-source/BUILD-INFO.txt 与 README-FLASH.txt 第六节)
